   *Probe finding (2026-09-27):* all of them exist in `OCC.Core.BRepGraph` under pythonocc-core 8.0.1:

4. Cross-dimensional transfer: the face generated by splitting a cell is the architecturally important
   entity. Is there a planned selector/key API for it, or should rules own it?

   *Probe finding (2026-09-27):* with `ShapeGrammar` `Divide`, the cut face is not reported as
   GENERATED from the cell. It is reported as `modified`, `sourceRole = tool`, Face -> Face,
   operation `Slice`: a modification of the dividing tool's face. It carries an empty dictionary, and
   both resulting cells inherit the source cell's dictionary. So the party wall is identifiable exactly
   (no geometric matching), but under a different relation from the one the brief assumes. Is
   `modified` + `tool` the intended public way to find it?
